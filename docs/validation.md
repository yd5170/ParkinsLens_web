## 이번에 실행하지 않은 항목

- 외부 Hugging Face 체크포인트를 이용한 실제 모델 추론과 성능 평가
- FSL BET·ANTsPy·PD25를 사용하는 로컬 전체 전처리
- 학습 전처리와 경량 전처리의 동등성, 환자 단위 split·클래스 순서와 체크포인트 재현성
- 실제 MRI에서 CAM 좌표·해부학적 ROI의 정확도
- Streamlit Community Cloud의 공개 배포, 동시 사용자 처리·응답시간·메모리 부하

## 남은 개선 사항

1. 학습 환경의 의존성 버전과 모델 아티팩트 revision을 고정하고 평가 manifest와 연결.
2. T2 표기가 없는 자동 후보는 수동 확인하거나 분석을 차단. 현재는 설명·슬라이스 수 기반 후보 선택.
3. DICOM 보조 변환의 방향·원점 처리 검증. 현재 보조 경로는 일반적인 oblique·다양한 촬영 방향을 모두 보장하지 않음.
4. 전체 입력 폴더의 누적 용량·압축 해제 크기에 대한 제한 보완.
5. 외부 ANTs 모듈에 대한 임시 registration 교체는 다중 세션 동시 실행 환경에서 별도 격리 필요.
6. 환자관리·과거 검사 결과는 가상 UI. 실제 서비스에는 인증·DB·검사 식별 및 저장 수명 관리 필요.
