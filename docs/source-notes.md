# 발표자료와 웹 구현의 대응

기준 자료: 사용자가 제공한 `3팀(팍스캔)_파킨슨렌즈_수정본(2).pptx`, 총 39쪽.

| 발표자료 | README에 반영한 내용 | 코드와 구분한 범위 |
|---|---|---|
| 9~10쪽 문제·솔루션 | MRI 업로드, 전처리, 분류, 결과 확인 흐름 | 조기 진단 효과·장비 간 편차 해소는 검증 성과로 주장하지 않음 |
| 14~16쪽 전처리·구조 | 볼륨 변환, 뇌 추출, 정합, 정규화, 56³ 처리 | 외부 로컬 v1은 ANTsPy 연결, N4 제외. Cloud는 BET·정합 제외. PPT의 FSL FLIRT·Z-score 표기와 구분 |
| 16쪽 서비스 기술 | Streamlit 화면·PDF 리포트 | FastAPI, Nilearn, Plotly는 이 웹 코드의 구현 기술로 나열하지 않음 |
| 19쪽 모델 결과 | CCA Held-out와 WOA 적용 보고값 | 현재 웹 체크포인트의 재측정 성능으로 해석하지 않음 |
| 23~26쪽 화면·보고서 | MRI 탐색, 클래스별 확률, 시각화와 보고서 | CAM은 CNN 분기 참고 시각화. 병변 검출·위축 측정·LLM 생성으로 주장하지 않음 |
| 32~35쪽 시연 | 업로드·전처리·환자관리 화면 이미지 | 과거 시연 이미지이며 현재 수정본의 화면 검증 자료는 아님 |

웹 코드에 있던 CCA 50.00% / WOA 43.48%라는 고정 안내는 PPT 보고값과 연결할 실험 식별 정보가 없어 UI에서 제거했습니다. PPT 보고값을 그 자리에 덮어쓰지 않았습니다.

팀 역할은 PPT 2쪽에 기재되어 있으나, 이 저장소만으로 개인별 코드 기여를 검증할 수 없습니다. 저장소 README와 포트폴리오에서는 팀 프로젝트의 전체 구현과 지원자 개인 기여를 구분해야 합니다.

기존 `results/` 문서는 원본 ZIP의 과거 개발 기록입니다. 과거 버전의 데모·모델 미연결 설명이나 당시 측정·커밋 언급을 현재 버전의 검증 결과로 사용하지 않습니다. 최신 검증 범위는 `docs/validation.md`를 따릅니다.
